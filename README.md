> 到点了，该鹿了，少年。
>
> 这不是签到，这是每天一次的赛博鹿角充电仪式。

基于 [早柚核心 / GsCore](https://github.com/Genshin-bots/gsuid_core) 的签到日历插件。发个 🦌，开盲盒、铺背景、出日历，今天的精神状态由鹿来宣布。

## 能干啥

- 🦌 每天一鹿，开出一张盲盒图。
- 📅 自动生成月历，哪天鹿过一眼就知道。
- 🖼️ 背景图优先读 `gsuid_core/data/DeerSignCalendar/sign-bj/`。
- 🧩 背景目录为空时，会去捞本机 XWUID 用户上传面板图。
- 🔁 控制台可以开「背景图不重复」：本月尽量不撞图，签到结果不变。
- 🌐 可以填外置渲染地址，把渲染压力丢给远方的鹿。

## 指令

## 图片放哪

### 背景图

手动塞背景图就放这里，别塞插件目录里：

```text
gsuid_core/data/DeerSignCalendar/sign-bj/
```

支持 `png / jpg / jpeg / webp`。这个目录空了，插件会自动去找本机 XWUID 的用户上传面板图。

### 盲盒图

塞进插件里的 `sign_images/`。每天开一张，本月同一天固定，不会今天鹿明天变成别的鹿。

## 控制台配置

- `背景图不重复`：开启后，同一用户本月尽量不重复背景图。
- `外置渲染地址`：填 `http(s)` 地址后优先远程渲染，翻车就回退本地。

## 帮助图

已接入 GsCore 自带帮助生成器和帮助注册。发：

```text
鹿帮助
```

就能看到那张“到点了，该鹿了”的帮助图。
